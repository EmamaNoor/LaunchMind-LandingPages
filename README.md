## How It Works

1. A startup idea is submitted to [LaunchMind](https://github.com/EmamaNoor/LaunchMind)
2. The **Product agent** creates a spec with personas, features and user stories
3. The **Engineer agent** generates a responsive single-file HTML landing page
4. A GitHub issue and feature branch (`landing/{product-name}`) are created automatically
5. The HTML is committed, a pull request is opened and the page is deployed to Vercel
6. The **QA agent** reviews the page and posts inline comments on the PR

No templates. No manual edits. Each page is unique to the startup idea.
