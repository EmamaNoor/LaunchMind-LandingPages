Key features

Real-Time Availability Dashboard

Interactive map and list view showing nearby buildings with available rooms, filtered by time, capacity, amenities, and price.

Instant Booking & Payment

Seamless booking flow with one-click reservation and secure payment (per hour or half-day), integrated with Stripe.

Smart Onboarding for Buildings

Step-by-step wizard to register building, add rooms with photos/amenities, set availability windows, and define cancellation policies.

User Ratings & Reviews

Post-session rating system for both freelancers and rooms, with verified reviews to build trust and quality.

Cancellation & Refund Engine

Configurable cancellation windows (e.g., 2-hour free cancel, 50% refund within 1 hour) with automated refunds and notifications.

How it works

1

Buildings set availability

Property managers register their building, add rooms, and set off-peak hours (evenings, weekends) to earn extra revenue without disrupting tenants.

2

Freelancers find and book

Freelancers search nearby rooms by time, capacity, and amenities. They book instantly with one click and pay securely via Stripe.

3

Check in and work

Automatic check-in via QR code at the building entrance gives freelancers secure access. After the session, both parties rate and review each other.
