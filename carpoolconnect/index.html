Key Features

Ride Matching

Algorithm that pairs drivers and riders based on route, schedule, and preferences.

Scheduling

Calendar-based system to set recurring or one-time rides with reminders.

Payment Splitting

Automated cost calculation and secure payment splitting among riders.

Safety Verification

User identity verification via ID upload, driver license check, and rating system.

Real-Time Tracking

Live GPS tracking of the ride for all participants with estimated arrival updates.
