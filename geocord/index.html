Join Discord servers based on where you are

GeoCord automatically adds and removes members based on physical proximity, enabling temporary communities for commuters, event attendees, and neighbors.

Get Started with GeoCord

Key Features

Geofenced Auto-Join

Users are automatically added to the server when their device enters a predefined geographic area, and removed when they leave.

Proximity-Based Channels

Channels are generated dynamically based on sub-locations within the geofence (e.g., train car, conference hall).

Time-Limited History

Messages are automatically deleted after a set period (e.g., 24 hours) to ensure privacy and reduce clutter.

Opt-Out and Privacy Controls

Users can manually leave the server, disable auto-join, or set a 'do not disturb' mode while still in range.

Moderation by Organizers

Event or area organizers can assign moderators, pin messages, and set rules that persist during the server's lifetime.

How It Works

1

Define a Geofence

Organizers set a geographic boundary around a train, event venue, or neighborhood. GeoCord handles the rest.

2

Auto-Join on Arrival

When a user enters the area, they are automatically added to the server. No manual search or invite needed.

3

Auto-Leave on Departure

Once the user leaves the geofence, they are removed from the server. No clutter, no spam, no permanent groups.
